# 500 ms 预览与静音预热对照

2026-10-07，版本 `0.1.0+7`、源码 `a664727`，base/small 各三轮真实在线字幕测试已完成。相比 [+6 Metal 对照](whisper-metal-benchmark.md)，首译中位数分别由 **3.336 → 2.322 秒**、**3.611 → 2.538 秒**；EOF 后最后译文确认分别由 **0.433 → 0.586 秒**、**0.688 → 1.013 秒**，尾部收尾更慢。更早的可修订预览伴随更多 ASR 和 MT 请求，不能只用首译数字描述整体变化。完整六轮数值事件、逐次推理、MT 请求和公开最终文本见 [本轮 JSON](benchmarks/whisper-500ms-2026-10-07.json)，旧值来自 [+6 JSON](benchmarks/whisper-metal-2026-10-07.json)。

## 协议与计时口径

Apple M2、16 GiB，whisper.cpp 1.8.1，multilingual base/small，六轮实际后端均为 **Metal**。按 **base1、small1、base2、small2、base3、small3** 交错运行；每轮启动新进程、加载一次模型并对一秒合成静音暖机，暖机输出不进入字幕或 MT。此前 GPU 编译缓存已被使用，因此这些结果不属于首次安装冷启动。

输入仍是公开 `whisper.cpp/samples/jfk.wav`：英语、单声道 16 kHz、11 秒，按实时节奏静默发送 110 个 100 ms 帧。六轮均 `status=ok`、0 丢帧。Whisper 本地识别，`qwen-mt-flash` 接收原文文本；本轮没有播放声音、使用扬声器/AirPods，也没有麦克风或系统声音采集。

字幕时间是控制器接纳非空事件的时刻，位于像素绘制之前。首源、首译与首个 final 均从**音频输入开始**计时，排除模型准备与系统授权等待，不能称为点击开始后的时间。EOF 收尾以实际输入结束事件为起点；firstDelta/completed 是 MT 请求阶段，preview 的 completed 不代表字幕已 final。

`firstStableSourceMs` 是首次收到 `stableSourceChars > 0` 的原文事件，长度以 UTF-16 code unit 计算。六轮实际首个 stable 均为 **partial、segment 1、revision 3、9 个 code unit**，不是首个 final。+6 没有记录这个字段，不能用旧版首源或 final 时间替代它。

首译中位数分别提前 **1.014 秒（30.4%）**、**1.073 秒（29.7%）**；首个译文 final 仅提前约 **23 ms、100 ms**，完整片段仍约在第 8 秒后确认。EOF 收尾中位数分别增加 **154 ms、325 ms**。这些是两版分开运行的观测差值；+7 同时改变了预览起点、间隔和预热，不能把全部差值归因于一个改动。

**500 ms 是预览配置间隔，不是每个词的 500 ms 延迟保证。** 本次从约第 1 秒开始识别增长窗口，稳定前缀需连续假设支持，MT 还有独立的 1.5 秒预览节流。原文快照增加不等于每次都重新翻译；最终片段仍走完整确认。早期原文和译文均可修订，普通 GUI 曾显示短预览“于是我的”；这次界面观察不用于定量字幕计时，也不能以最终结果反推早期预览正确。

## MT 请求与逐次 ASR

+6 每轮为 **8 次 preview + 2 次 final = 10 次 ASR**、6 个 MT requestStarted。+7 每轮为 **20 次 preview + 2 次 final = 22 次 ASR**；base 每轮 7 个 MT 请求、small 每轮 8 个。计算与请求量增加，功耗和电量消耗未测。

| +7 MT 记录 | base 三轮 | small 三轮 |
| --- | ---: | ---: |
| requestStarted | 21 | 24 |
| completed | 18 | 24 |
| 缺少终止事件 | **3** | 0 |
| 已记录 failed / canceled / retry | 0 / 0 / 0 | 0 / 0 / 0 |
| requestStarted → firstDelta，ms | 198.772（164.862–1556.018），n=18 | 191.995（165.726–241.064），n=24 |
| requestStarted → completed，ms | 260.217（220.825–1638.280），n=18 | 268.713（215.002–342.530），n=24 |

全六轮 **45 个 requestStarted，42 个 completed**；42 个有效配对 firstDelta 中位数 **196.544 ms（164.862–1556.018）**。base 每轮第二段 revision 6 预览随后被 revision 7 final 替代：前两轮只记录 requestStarted/connectionReady，第三轮只记录 requestStarted，均无 firstDelta 或终止事件。这里的 0 canceled 是**没有记录取消阶段**，不能据此断言实际没有取消，也不能把缺少终止记录当作 HTTP 失败或已完成。+6 的 36 个请求全部有 completed；本轮 submit 没有独立事件，仍为 `null`，requestStarted 不能称为队列提交时刻。

base3 第二段 final 请求 firstDelta 为 **1556.018 ms**、completed 为 **1638.280 ms**，其中 requestStarted→connectionReady 为 **1425.945 ms**，该轮 EOF 后译文 final 达 **1945.479 ms**。同轮较早的第二段 revision 3 预览 firstDelta 为 **582.498 ms**。这些异常均保留；已有阶段记录不能进一步定位网络、服务端或客户端原因。

以下 ASR 耗时分布按每次 completed 事件统计，包含六轮所有调用，单位 ms，中位数（最小–最大）。预览是 1–7.5 秒增长快照，final 是 8 秒和 3.5 秒窗口；RTF 是当次耗时除以当次快照长度。

本轮每个 started 配置间隔和 completed 后更新的下一间隔均为 **500 ms**，旧轮均为 1000 ms。preview 耗时/started 间隔比值中位数为 base **0.3284**、small **0.6914**，最大 **0.4546、0.8596**，没有超过 1；这不是实际字幕发布节奏或队列等待测量。

EOF 当时仍有一次 preview 在处理，随后还需 final；每轮各有两次 final。final 快照终点到推理开始的中位数为 base **84.063 ms（1.334–182.221）**、small **174.685 ms（0.682–423.603）**，旧版分别为 **1.649、2.476 ms**。这个时间含音频交付、调度与可能等待，缺少独立入/出队时间，不能全部称为排队。它与新轮尾部更慢同时出现，不能据本样本宣称所有延迟都下降。preview 快照终点到开始的最小值分别为 **−0.067、−0.236 ms**，按原始带符号值保留，不裁为零。

## 最终文本与证据范围

六轮英语 final 词序列均为：

```text
And so my fellow Americans, ask not what your country can do for you.
Ask what you can do for your country.
```

按上游公开 22 词参考、小写 ASCII 词、忽略标点计算，每轮均 **S=0、D=0、I=0、N=22，final WER=0%**。重复同一样本不是六个独立准确率样本；该分数不评估 partial 的错误、稳定性或早期译文质量。

base1/base3 与 small 三轮最终中文均为：

```text
因此，我的美国同胞们，请不要问国家能为你们做些什么。
问问你能为你的国家做些什么。
```

base2 第一段为“因此，我的美国同胞们，请不要问你的国家能为你做些什么。”，第二段相同。因此 small 三轮最终文本一致，base 中文有措辞差异。逐段核对，六轮均保留**美国同胞称呼、不要问的否定、国家为你做事、你为国家做事**四项含义，没有方向颠倒或核心遗漏。五轮两段人称从“你们”变为“你”，“请”“问问”也带来风格变化；两段拆分削弱了演说的连续修辞。这是定性语义核对，不换算成翻译准确率百分比。

本轮验收另有 **123 项 Flutter 测试通过、1 项可选测试跳过**，真实 tiny Metal 静音暖机及取消/恢复、Swift 打包与签名检查通过，记录见 [验收文档](testing.md)。这些工程检查和本次延迟测量分别提供证据。当前结果只覆盖一个干净 11 秒英语→中文样本及本机环境；长对话、噪声、中文识别、其它语言、逐词时延、预览改写率、功耗均未评测。旧 CPU small 只有一轮，不是本轮版本的公平后端对照，也不能用于单独归因此次改动。
