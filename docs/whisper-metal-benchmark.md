# Metal 与词级稳定预览

2026-10-07，版本 `0.1.0+6`，实现提交 `6ca9d6f`，已安装到 `/Applications/LumaCaption.app`。原生推理与在线字幕对照均已完成，数值证据分别见 [原生推理 JSON](benchmarks/whisper-metal-native-2026-10-07.json) 和 [六轮在线字幕 JSON](benchmarks/whisper-metal-2026-10-07.json)，测试与安装记录见 [验收文档](testing.md)。

## 已完成的改动

- macOS Whisper 启用 Metal，GPU 内核源码嵌入 dylib；初始化失败可回退 CPU，界面使用实际后端名称。没有加入 CoreML 或量化模型。
- 第 2 秒开始预览，后续间隔依推理耗时在 1–3 秒之间调整。忙时只保留最新待处理预览，最终识别优先，避免增长窗口持续排队。
- 连续两次识别按词比较稳定前缀，忽略一般标点与大小写；词内撇号仍有语义区别。保留末尾一个词可修订，短前缀等待更多音频。最终完整文本继续校正译文，不把预览当作确认文本导出。
- 下一窗口使用最多 32 个空格分隔词、256 个 Unicode 字符的已确认前文；同一增长窗口的未确认假设不回灌自身。保留最长 8 秒最终窗口和重叠去重。
- 新增逐次本地推理的数值计时；紧急停止先失效代次、取消推理与翻译，再等原生停止和旧 worker 收尾，防止旧结果进入新会话。

## 已安装库的 base 与 small 对比

Apple M2、16 GiB、arm64，whisper.cpp 1.8.1。直接加载已安装应用的 dylib，每个模型建立一个 handle，一次暖机单列，随后同 handle 推理三次。输入为公开 `samples/jfk.wav`，英语、单声道 16 kHz、11 秒，一次性传入；8 线程、greedy、final 的默认温度回退、空 prompt。不播放音频，不使用麦克风、AirPods 或系统采集，不调用在线服务。

以下耗时仅为 `luma_run`，不包含模型加载、音频积累、稳定前缀等待、MT、采集或 UI。两模型均为 multilingual 原始 GGML 权重，实际后端均为 **Metal**。

| 指标 | base | small |
| --- | ---: | ---: |
| 三次暖态推理中位数 | **180.376 ms** | **452.374 ms** |
| 暖态范围 | 177.910–181.646 ms | 452.265–478.826 ms |
| 单列的首次推理 | 407.956 ms | 594.028 ms |
| 原生 luma_create（直接加载） | 195.351 ms | 475.526 ms |
| 暖态 RTF（推理耗时÷11 秒） | 0.0164 | 0.0411 |

当前 GPU 编译缓存已被此前的初始化使用，不能把本进程模型加载数字称为首次安装冷启动。模型持续驻留后，base 在这段样本的暖态本地计算约比 small 少 60%；这是相同参数下的模型对比，不是应用端到端提速比例。

八次最终结果（每模型一次首次调用、三次暖态）均与同一 22 词参考完全匹配，忽略标点和大小写后 WER=0%，三次暖态文本分别一致。这只证明该公开干净样本，不证明长对话、中文、噪声、专名的总体准确率，也没有测出预览改写率。

## 实时节奏文件输入的在线字幕对照

同一实现按 **base1、small1、base2、small2、base3、small3** 交错运行，每模型三轮，实际后端均为 Metal、模型均为 multilingual。每轮静默送入同一个 11 秒公开 JFK 文件，按实时节奏发送 110 个 100 ms 帧；六轮均 `status=ok`、0 丢帧。Whisper 在本机识别，`qwen-mt-flash` 只接收原文文本。没有播放声音或采集麦克风、AirPods、系统声音。

字幕计时记录控制器接纳非空事件的时刻，位于 UI 调度与像素绘制之前。下表以**音频输入开始**为起点，排除模型加载和准备；它不是点击开始后的时间。partial 可以修订，final 才是片段确认。EOF 收尾以实际文件输入结束事件计时。单位秒，单元格为**中位数（最小–最大）**，每列 `n=3`。

### 准备与模型加载：保留首轮系统等待

base1 的 `setupMs=1672407.974`、`preparationMs=1672408.838`，约 **27 分 52 秒**。音频开始之前，被动进程采样确认主线程在 `SecItemCopyMatching` 等待用户处理系统钥匙串授权；用户放行后本轮继续完成。这属于准备阶段中的系统授权等待，不能归因于 Whisper 推理或 MT。入口 `loadingModel` 是当时尚未更新的阶段标签，不能作为真实阻塞点证据。本轮没有删除或重跑来替代异常值。

其余五轮 preparation 为 **7.504–10.620 ms**。完整三轮统计仍保留首轮：base preparation 中位数 **10.015 ms（8.893–1672408.838）**，small 为 **10.022 ms（7.504–10.620）**。从 base1 准备计时起点到首译共 **1675745.020 ms**；这仍不是点击时刻计时，且模型加载单独记录。

### MT 请求与逐次本地推理

每轮记录 6 个 MT 请求：4 个预览原文请求、2 个 final 原文请求。两模型各 18 个、总共 **36 个全部完成**，记录中失败、取消、重试均为 0。没有单独的 MT 队列提交事件，故 JSON 的 submit 时间为 `null`；上表报告的是 **requestStarted**，不是提交时刻。下表按同一全局单调时钟配对 requestStarted→firstDelta/completed，单位 ms，`n=18`/模型。

| MT 请求耗时，中位数（最小–最大） | base | small |
| --- | ---: | ---: |
| 首增量 firstDelta | 189.520（170.507–226.348） | 192.532（159.443–227.593） |
| 请求 completed | 258.474（217.224–332.665） | 276.666（209.146–663.867） |

全部 36 个请求的 firstDelta 中位数为 **191.197 ms（159.443–227.593）**。small3 第一段的 revision 6 预览请求首增量为 **192.971 ms**，完成为 **663.867 ms**；该较长完成等待保留，现有记录不能区分服务端、网络或客户端原因。预览请求 completed 后，其译文仍可修订，不能等同于字幕 final。

### 最终文本与样本质量

六轮最终原文词序列一致。按同一公开 22 词 JFK 参考、小写 ASCII 词、忽略标点计算，每轮均 **S=0、D=0、I=0、N=22，WER=0%**。重复同一样本不增加独立样本数量；这个指标只评估最终英语原文词序列，不评估 partial 稳定性或中文翻译准确率。

base 与 small 的六轮最终中文文本完全一致，均为两段：

```text
因此，我的美国同胞们，请不要问国家能为你们做些什么。
问问你能为你的国家做些什么。
```

逐段双语复核确认四项核心含义均保留：美国同胞的称呼、“不要问”的否定、国家为你做事的方向、你为国家做事的方向。没有观察到核心遗漏、方向颠倒或实质性添加。两段翻译削弱了原句的显式修辞连接，称呼从“你们”切换为“你”；“请”和“问问”是风格变化。这是定性样本核对，不换算为翻译准确率百分比。

此前 CPU small 仅有一轮：首译 **9.892 秒**，首个 MT 请求开始 **9.655 秒**，首增量等待约 **237 ms**，最后一个推理窗口 **2227 ms**，见 [旧版预览报告](whisper-mt-preview-benchmark.md)。该历史轮的版本、后端及预览策略均与当前对照不同，不能用它单独归因 Metal、稳定前缀或调度改动，也不能与完整 11 秒原生调用直接计算应用提速倍数。当前三轮结果只适用于这个公开干净样本及本次环境，未覆盖长期运行、噪声或其它语言。

103 项自动测试通过、1 项可选 FFI 跳过，完整 Dart 静态分析无问题；真实 tiny FFI 的新 ABI、Metal、prompt、取消与恢复另已通过。CoreML、量化、长音频与噪声评测未纳入本轮。
