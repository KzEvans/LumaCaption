# Qwen 3.8 实时翻译与 Whisper → Qwen-MT 样本基准

2026-10-07 · LumaCaption `0.1.0+3` · 源码 `04b3b58`

在同一段公开的 11 秒 JFK 英语样本上，Qwen 3.8 实时路径首个译文事件的中位时间为 **3.277 秒**，本地 Whisper → Qwen-MT 为 **9.010 秒**。两条路径各重复三次，均为真实 API 路径且 `status=ok`。这反映当前应用实现及本次运行环境，不能单独归因于模型速度，也不能推广为普遍准确率结论。

## 路径、输入与环境

| 项目 | 本次设置 |
| --- | --- |
| 云端实时路径 | `qwen3.8-livetranslate-flash-realtime`，上传 PCM 音频并接收原文、译文流 |
| 本地识别＋文本翻译路径 | Whisper tiny 多语言模型 → `qwen-mt-flash`；Whisper 在本机识别，在线翻译仅上传识别后的原文文本 |
| 本地后端 | whisper.cpp `1.8.1`，CPU + Accelerate，未启用 Metal 推理 |
| 样本 | 上游 `.tools/whisper.cpp/samples/jfk.wav`，11 秒、单声道、16 kHz |
| 输入节奏 | 按实时节奏送入 110 个 100 ms 音频帧；六次运行均无丢帧 |
| 机器与软件 | Apple M2、16 GiB；macOS 27.2 beta；Flutter 3.47.6、Dart 3.13.5 |

本次使用静默文件输入，没有通过扬声器或 AirPods 播放，没有采集麦克风或系统声音。它验证文件音频到字幕事件的处理路径，不构成采集设备或 GUI 像素显示验收。

## 计时口径与结果

计时使用单调时钟，记录控制器收到、通过接纳过滤的非空字幕事件。计时点位于 UI 更新调度和像素绘制之前，因此下表是**字幕事件接收时间**。首个事件可以是尚可修订的 partial；final 表示片段确认。

起点为文件音频开始送入的时刻，排除连接准备和本地模型加载。音频结束后的时间以实际 EOF 事件为起点，不直接用固定的 11 秒替代。每个单元格为 **中位数（最小–最大）**，单位秒，`n=3`。

| 指标 | Qwen 3.8 实时 | Whisper → Qwen-MT |
| --- | ---: | ---: |
| 首个原文字幕事件 | 3.237（3.150–3.362） | 2.484（2.324–4.774） |
| 首个译文字幕事件 | **3.277（3.171–3.414）** | **9.010（8.937–9.065）** |
| 首段原文 final | 11.876（11.815–11.972） | 8.451（8.361–8.486） |
| 首段译文 final | 11.877（11.815–11.972） | 9.124（9.041–9.188） |
| 最后一段译文 final 相对 EOF | 0.875（0.813–0.971） | 0.684（0.673–12.446） |
| 本地模型加载，单独记录 | 不适用 | 0.845（0.779–0.942） |

云端路径在音频流尚未结束时输出译文。当前本地分段器每 2 秒提供可修订预览，片段最长为 8 秒；控制器只把 final 原文提交给文本 MT。这次首段原文约在 8.4 秒确认，随后才进入 MT，解释了本地路径“原文预览较早、首个译文较晚”的现象。该配置见 [`audio.dart`](../lib/core/audio/audio.dart) 与 [`controller.dart`](../lib/app/controller.dart)；这不是两种模型在相同流式策略下的纯推理速度比较。

### 保留第三次 MT 的延迟异常

Whisper → Qwen-MT 第三次运行的第二段原文 final 在音频起点后 **11.330 秒**收到，第二段首个译文及 final 分别在 **23.447 秒**收到。原文确认到该段首个译文的间隔为 **12.117 秒**，最后译文 final 相对 EOF 为 **12.446 秒**。原文收尾仍在 EOF 后约 **0.328 秒**完成。

额外等待发生在本地原文确认之后、译文事件接收之前。现有计时不能区分服务端、网络或客户端原因。统计保留此运行，没有将它排除；仅看 0.684 秒的中位数会掩盖这次收尾等待。

## 原文识别与译文检查

参考文本来自 [whisper.cpp v1.8.1 README 的 JFK 样本输出](https://github.com/ggml-org/whisper.cpp/blob/v1.8.1/README.md)，包含 22 个词：

```text
And so my fellow Americans ask not what your country can do for you ask what you can do for your country
```

WER 按小写 ASCII 词比较，忽略标点，公式为 `(S + D + I) / N`。两条路径的三次运行均为 **S=0、D=0、I=0、N=22，WER=0%**。两条路径各自的最终文本在三次运行中一致。重复同一个样本不是更多独立样本；这个结果只说明此样本的最终原文词序列匹配，不衡量标点、分段、partial 稳定性或中文翻译准确率。

Qwen 3.8 实时路径的最终译文：

```text
因此，我的美国同胞们，不要问你的国家能为你做什么，而要问你能为国家做些什么。
```

Whisper → Qwen-MT 路径的最终译文，两段分别翻译：

```text
因此，我的美国同胞们，请不要问国家能为你们做些什么。
问问你能为你的国家做些什么。
```

双语定性检查的四个要点如下：

| 核心含义 | Qwen 3.8 实时 | Whisper → Qwen-MT |
| --- | --- | --- |
| 面向美国同胞的称呼 | 保留 | 保留 |
| “不要问”的否定 | 保留 | 保留 |
| 国家为你做事的方向 | 保留 | 保留 |
| 你为国家做事的方向 | 保留 | 保留 |

此样本中没有观察到核心含义缺失、方向颠倒或实质性添加。云端译文用“不要问……而要问”连成一句，显式保留修辞对照；第二处“国家”省略的所属关系可从上下文恢复。文本 MT 的分段削弱了两句之间的显式连接，并从“你们”切换为“你”。“请”和“问问”属于措辞风格变化。上述检查不换算成翻译准确率百分比。
